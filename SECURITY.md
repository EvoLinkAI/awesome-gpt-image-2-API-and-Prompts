# Security Policy

## Scope

This repository primarily contains public prompt examples, media, documentation, structured source records, and maintenance scripts. Security reports may concern:

- accidental secrets or private data committed to the repository;
- unsafe behavior in a repository script;
- malicious links or media;
- supply-chain or workflow issues that could affect contributors.

EvoLink platform, billing, account, and production API incidents are outside this repository's maintenance scope, but they can use the same private contact below for routing.

## Report privately

Do not open a public issue for an unpatched vulnerability or exposed secret.

Email `support@evolink.ai` with the subject prefix `[Security][awesome-gpt-image-2]`. Include:

- the affected file, URL, commit, or workflow;
- the impact and conditions required to reproduce it;
- minimal reproduction steps;
- any suggested mitigation;
- whether the report contains sensitive information that should not be redistributed.

Please remove live credentials and unnecessary personal data from the report. Maintainers will acknowledge and triage reports privately, coordinate a fix when the issue is in scope, and publish a summary only when disclosure is safe.

## Supported versions

Only the current default branch is maintained. Historical prompt data and media are not separate supported software versions.
